# TORANEX Official Website

Arabic-first responsive corporate website and digital portfolio for TORANEX.

## Pages
- Home: `index.html`
- About: `about.html`
- Services: `services.html`
- Portfolio: `portfolio.html`
- Contact: `contact.html`

## Stack
Static HTML and CSS. The site is designed for mobile and desktop, with Arabic RTL layout. No database is required for the public portfolio at this stage.

## Deployment
Connected to Vercel through the GitHub repository `568140/toranex-official`, production branch `main`.
